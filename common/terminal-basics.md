## ⚡ Quick Core Commands

| Command | Purpose | Example |
|---|---|---|
| `pwd` | Print working directory | `pwd` |
| `ls -la` | List all files in detail | `ls -la` |
| `cd <dir>` | Change directory | `cd /var/log` |
| `mkdir -p` | Create nested directories | `mkdir -p a/b/c` |
| `touch <file>` | Create empty file or update timestamp | `touch note.txt` |
| `cp -r` | Copy files or directories recursively | `cp -r src/ dest/` |
| `mv` | Move or rename files | `mv old.txt new.txt` |
| `rm -r` | Remove files or directories | `rm -r folder/` |
| `which <cmd>` | Find executable location | `which bash` |
| `grep -rn` | Search text recursively with line numbers | `grep -rn "root" /etc/` |
